ASSIGNMENT: DEVELOP AND DEPLOY A BASIC SMART CONTRACT USING SOLIDITY

PROJECT: SIMPLE STUDENT RECORD SMART CONTRACT

This assignment uses Remix IDE, an online Solidity development
environment. No software installation is required.

1.  OBJECTIVE

Create a basic smart contract that can: - Store a student’s name. -
Store a student’s roll number. - Retrieve the stored student details. -
Update the student details.

2.  OPEN REMIX IDE

3.  Open a web browser.

4.  Visit https://remix.ethereum.org/

5.  Wait for Remix IDE to load.

6.  In the File Explorer, create a new file named StudentRecord.sol.

7.  WRITE THE SMART CONTRACT

Copy the following Solidity code into StudentRecord.sol:

// SPDX-License-Identifier: MIT pragma solidity ^0.8.20;

contract StudentRecord {

    string public studentName;
    uint public rollNumber;

    // Store student details
    function setDetails(
        string memory _name,
        uint _rollNumber
    ) public {
        studentName = _name;
        rollNumber = _rollNumber;
    }

    // Retrieve student details
    function getDetails()
        public
        view
        returns (string memory, uint)
    {
        return (studentName, rollNumber);
    }

}

4.  COMPILE THE CONTRACT

5.  Open the Solidity Compiler tab on the left side of Remix.

6.  Select compiler version 0.8.20, or another compatible 0.8.x version.

7.  Click the Compile StudentRecord.sol button.

8.  Confirm that compilation succeeds and that Remix displays a green
    tick or successful compilation message.

9.  DEPLOY THE CONTRACT

10. Open the Deploy & Run Transactions tab.

11. Under Environment, select Remix VM.

12. Under Contract, select StudentRecord.

13. Click the orange Deploy button.

14. Find the deployed StudentRecord contract under Deployed Contracts.

15. Expand it to see the available functions.

Note: Remix VM deploys the contract to a local blockchain environment
inside Remix. This is suitable for a basic practical demonstration
unless the faculty specifically requires deployment to a public test
network.

6.  TEST THE CONTRACT

TEST 1: STORE STUDENT DETAILS

1.  Under the deployed StudentRecord contract, find the setDetails
    function.
2.  Enter the following values:
    -   Name: Rahul
    -   Roll number: 101
3.  Click setDetails.
4.  Wait for the transaction to complete successfully.

TEST 2: RETRIEVE STUDENT DETAILS

1.  Click the getDetails function.
2.  Check the returned values. The expected result is:
    -   Student name: Rahul
    -   Roll number: 101

TEST 3: UPDATE STUDENT DETAILS

1.  In setDetails, enter:
    -   Name: Amit
    -   Roll number: 102
2.  Click setDetails.
3.  Wait for the transaction to complete.
4.  Click getDetails again.
5.  Confirm that the updated result is:
    -   Student name: Amit
    -   Roll number: 102
